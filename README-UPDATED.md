# Bite House – التحديثات

تمت إضافة الوظائف المطلوبة:

- Dark / Light Mode مع حفظ الاختيار في المتصفح.
- إدارة الفروع من لوحة التحكم وإضافة فرع جديد.
- اختيار فرع واحد أو أكثر عند إنشاء أو تعديل القسم.
- اختيار فرع واحد أو أكثر عند إنشاء أو تعديل الصنف.
- اختيار فرع واحد أو أكثر عند إنشاء أو تعديل العرض.
- اختيار الفروع يتم بالضغط على كارت الفرع، ويظهر ✓ عند الاختيار.
- البيانات العامة للمنيو يتم فلترتها تلقائيًا حسب الفرع المختار.
- البيانات القديمة تم ربطها بالفروع الحالية حتى تظل ظاهرة كما كانت.
- عند إنشاء عرض، لا يمكن اختيار صنف غير موجود في كل الفروع المختارة للعرض.

## التشغيل

بعد فك الضغط:

```bash
npm install
npm run dev
```

ثم افتحي الرابط الذي يعرضه Vite.

للوحة التحكم استخدمي المسار `/admin` مع بيانات الدخول الموجودة في ملف `.env` الخاص بالمشروع.

## ملاحظة

الملف المرفق لا يحتوي على `node_modules` أو `dist`؛ يتم تثبيت الحزم محليًا بواسطة `npm install`.
